# THE PITCH Voice Beta

## มีอะไรเพิ่ม
- กด 🎙️ เพื่อเริ่มพูด และกดอีกครั้งเพื่อหยุด
- ส่งเสียงไปแปลงเป็นข้อความด้วย AI
- NPC ตอบแบบ AI ไม่มีสคริปต์
- NPC สร้างเสียงตอบกลับด้วย AI

## วิธีรัน
1. ติดตั้ง Node.js
2. เปิด Terminal ในโฟลเดอร์นี้
3. `npm install`
4. คัดลอก `.env.example` เป็น `.env`
5. ใส่ OPENAI_API_KEY ของคุณใน `.env` (ห้ามอัปโหลดไฟล์นี้)
6. `npm start`
7. เปิด http://localhost:3000
8. อนุญาตการใช้ไมโครโฟน

หมายเหตุ: เว็บที่เปิดผ่าน localhost ใช้ไมโครโฟนได้สำหรับการทดสอบ; เมื่อนำขึ้นเว็บจริงควรใช้ HTTPS
เครดิตทั้งหมดเป็นเงินสมมติในเกม
